# Sekenani Youth Self Empowerment Group Website

A responsive single-page website for Sekenani Youth Self Empowerment Group in Sekenani, Kenya.

## Included
- Responsive layout for desktop, tablet and mobile
- Attached group logo integrated throughout the site
- Animated hero section with layered parallax motion
- Hover effects and reveal-on-scroll animations
- Scrolling values marquee
- Animated GIF accents
- Community, programs, impact, stories, gallery and contact sections
- Contact form that opens the visitor's email app using `mailto:`
- Accessible reduced-motion support

## Customising
Replace the placeholder visual tiles in `styles.css` with your own photographs when available. Add real project statistics and member stories in `index.html` as the group collects them.

Open `index.html` in a browser to view the website.
